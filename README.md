# Binarytacora

Bitácora de trading de opciones binarias para Windows (IQ Option, Exnova y Casa Trade).
Registra tus operaciones automáticamente, guarda las velas alrededor de cada una y te ayuda a
llevar un diario y estadísticas de tu operativa. Solo lee tu cuenta: nunca abre ni cierra operaciones.

## Descargar

Descarga el instalador `Binarytacora_<versión>_x64-setup.exe` de la
[última versión](https://github.com/dagamdev/binarytacora-releases/releases/latest).

La app se actualiza sola: cuando hay una versión nueva te avisa y la instala si lo aceptas.

> Windows puede mostrar "Windows protegió su PC" la primera vez: pulsa **Más información → Ejecutar de todas formas**.

Este repositorio solo contiene los instaladores.
